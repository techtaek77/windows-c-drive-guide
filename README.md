# 윈도우는 왜 C부터 시작할까?

윈도우 하드디스크가 A가 아니라 C 드라이브부터 시작하는 이유를 플로피 디스크 시절 역사와 벨로키의 부팅 실험으로 설명하는 TECHTAEK 교육 자료.

- 공개 페이지: https://techtaek77.github.io/windows-c-drive-guide/
- index.html 하나에 벨로키 이미지와 드라이브 문자 배정 실험을 포함한다.
- 부팅 실험은 교육용 단순 모델이며 실제 DOS 에뮬레이터가 아니다.
- 벨로키 삽화는 AI 생성 TECHTAEK 캐릭터 그림이다.
